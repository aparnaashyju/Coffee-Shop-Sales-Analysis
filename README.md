☕ Coffee Shop Sales Analysis – Power BI Project

📌 Project Overview
This project focuses on analysing coffee shop sales data using Microsoft Power BI. The main objective is to understand business performance by analysing sales across different products, store locations, and months.

🎯 Project Objectives
- Analyse overall coffee shop sales performance.
- Identify top-performing products and categories.
- Understand sales trends across different months.
- Compare sales performance across store locations.
- Generate meaningful business insights using data visualisation.

🛠️ Tools & Technologies
- Power BI – Dashboard development and data visualisation.
- Power Query – Data cleaning and transformation.
- DAX – Measures and calculations.
- Microsoft Excel – Dataset handling.

📊 Key Features
- Interactive dashboards.
- Sales and product performance analysis.
- KPI tracking.
- Monthly sales trend analysis.
- Store-wise performance analysis.
- Slicers, filters, and drill-through functionality.
- Key Influencers and Decomposition Tree.

📁 Project Files
- "MAIN_PROJECT.pbix" – Power BI project file.
- "Coffee Shop Sales (2).xlsx" – Dataset.
- "PPT_coffeeshop.pdf" – Project presentation.

💡 Key Insights
- Coffee is the highest-contributing product category, accounting for approximately 38–39% of total sales.
- The report helps identify sales trends and product performance.
- Interactive visuals make it easier to explore business performance.

📚 Learning Outcome
This project helped me gain practical experience in data cleaning, data transformation, data modelling, DAX calculations, and interactive dashboard development using Power BI.
